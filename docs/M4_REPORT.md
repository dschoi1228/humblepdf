## 만든 것

- **core**
  - `signature::normalize`: PNG·JPG → EXIF 방향 반영 → 긴 변 2000px 이하(Lanczos3) → RGBA PNG
  - 서명 파일이 없을 때의 오류 코드를 `signature_missing`으로 구분했다.
- **보관함** (`src-tauri/src/signatures.rs`, D30)
  - `%APPDATA%\com.pdfeditor.app\signatures\`에 `<id>.png`와 `index.json`을 둔다.
  - 무작위 id, 원자적 쓰기, 이름 1~100자
  - Tauri 명령 5개는 별도 스레드에서 실행한다. 저장할 때는 보관함 폴더를 core에 넘긴다.
- **프런트엔드**
  - 서명 저장소(목록, 고른 서명, 이미지 blob URL)
  - 보관함 대화상자(미리보기, 추가, 이름 변경, 삭제)
  - 편집 막대의 서명 도구(S)와 서명 고르기
  - 클릭 배치(화면 기준 페이지 폭 25%, 똑바로, 페이지 안)
  - 모서리 핸들로 비율을 유지하는 크기 조절
  - 썸네일에도 그린다. 이미지가 없으면 빨간 점선 상자를 보인다.
- **브라우저 모드**
  - 메모리 보관함을 쓴다(`?signatures=`로 미리 넣는다).
  - `/__export`가 서명 PNG를 받아 CLI `--signatures`로 넘긴다.
- **문자열:** ko, en, ja
- **사람 확인 샘플:** `npm run sample`이 `out/m4_sample.pdf`(6쪽, 서명 12개)를 만든다.

## 계획과 달라진 점, 발견한 문제

1. **도구 선택 함수를 따로 뺐다** (`src/app/toolActions.ts`). 서명 보관함은 백엔드(pdf.js 포함)를 불러온다. 그래서 `objectActions.ts`에 두면 Node에서 도는 단위 테스트가 그 파일을 불러올 수 없다.
2. **등록 흐름을 줄였다.** 계획은 "파일 선택 → 이름 → 등록"이었다. 실제로는 파일을 고르면 파일 이름으로 바로 등록하고, 이름은 목록에서 바꾼다. 단계가 하나 줄고 결과는 같다.
3. **E2E에서 고른 서명의 id는 배치 전에 읽는다.** 배치하면 선택 도구로 돌아가 서명 고르기 막대가 사라지기 때문이다. 테스트만 고쳤다.
4. **타입 검사 명령:** 작업 중 `tsc -p tsconfig.json`이 프로젝트 참조 때문에 아무것도 검사하지 않는다는 것을 알았다. 실제 검사는 `npm run lint`의 `tsc -b`다. M3 커밋도 `npm run lint`로 검사했으므로 영향은 없다.

## 남은 위험

- **흰 배경이 있는 서명 이미지:** 흰 배경 JPG를 등록하면 흰 상자째로 놓인다. 자동 투명화는 SPEC 후순위다. 투명 PNG를 쓰도록 안내하는 문구를 M7에서 검토한다.
- **보관함 목록 파일이 손상되면** 목록을 읽지 못한다는 오류만 보인다. 복구 기능은 없다.

받은 의견과 고친 것
- **서명할 때마다 도구를 다시 골라야 한다.** 서명 도구를 놓은 뒤에도 남게 했다. 클릭할 때마다 하나씩 놓이고, Esc나 V로 나온다(D31 변경).
- **포인터에 서명이 보이지 않는다.** 서명 도구에서는 고른 서명이 놓일 크기 그대로 반투명하게 포인터를 따라다니게 했다.
- E2E로 확인했다: 도구 유지, 미리보기 위치가 포인터 중심과 2px 이내, 두 번째 클릭으로 하나 더 놓기, Esc로 미리보기가 사라지는지.
- 다시 확인했다(2026-11-23): 도구 유지와 미리보기 모두 정상이다. M4를 마쳤다.

## 사람 확인 점검표

`npm.cmd run tauri dev`로 앱을 연다. 실제 서명이 아닌 아무 PNG·JPG(예: `tests\fixtures\signatures\sig-demo.png`, `tests\fixtures\exif_rotate90.jpg`)로 확인해도 된다.

1. **보관함**
   - 편집 막대의 서명 도구(S)를 누르면 비어 있는 보관함이 열리는가
   - PNG와 JPG를 추가한다. 미리보기가 맞는가(JPG는 방향이 바로 서야 한다)
   - 이름을 바꾸고 하나를 지운다.
2. **유지:** 앱을 닫았다가 다시 열면 보관함 목록과 이름이 그대로인가.
3. **배치와 편집**
   - 서명을 골라 페이지를 클릭한다(회전된 페이지 포함). 화면에서 똑바로, 페이지 폭의 1/4 크기로 놓이는가
   - 서명 도구에서 고른 서명이 포인터를 따라 미리보기로 보이는가. 클릭할 때마다 하나씩 놓이고, Esc로 나오는가
   - 모서리 핸들로 크기를 바꾸면 비율이 유지되는가
   - 옮기기, 방향키, Delete, 실행 취소가 되는가
4. **삭제 규칙:** 배치한 서명을 보관함에서 지우려 하면 거부되고 쪽 번호를 알려 주는가.
5. **다른 뷰어:** `npm.cmd run sample`이 만든 `out\m4_sample.pdf`와 앱에서 저장한 파일을 Acrobat Reader, Edge, Chrome에서 연다.
   - 서명이 주석으로 선택되거나 옮겨지지 않는가
   - 투명 배경이 유지되어 아래 글자가 보이는가
   - 세 뷰어의 모습이 같은가
