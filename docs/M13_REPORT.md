## 만든 것

- **하이라이트 도구:** 글자 위(글자 상자에서 4px 안)를 누르면 M12의 끌어 선택하기로 텍스트를 고르고, 놓으면 줄마다 quad 하나인 하이라이트를 만든다. 글자 위에서는 커서가 텍스트 커서다. 그 밖의 곳은 지금처럼 상자다.
- **H 단축키:** 본문 텍스트를 선택한 상태면 그 텍스트를 하이라이트하고 선택한다. 아니면 지금처럼 하이라이트 도구를 고른다. 단축키 도움말과 도구 툴팁에 세 언어로 적었다.
- **quad 계산** (`src/viewer/textLayer.ts`의 `selectionQuads`, `src/viewer/readingFrame.ts`)
  - 가로 범위는 선택한 글자, 세로 범위는 pdf.js가 놓은 글자 상자(글꼴 크기 높이)다.
  - 같은 줄은 하나로 합친다.
  - 회전한 쪽은 읽는 방향 좌표계에서 계산하고, 사용자 공간 변환은 좌표 모듈로 한다.
- **여러 쪽:** 쪽마다 객체 하나, Undo 한 칸이다.
- **샘플:** `npm run e2e`가 앱으로 직접 끌어 만든 `out/m13_sample.pdf`를 쓴다. 0°·90°·180°·270° 네 쪽에 색을 달리한 세 줄 하이라이트와 H로 만든 단어 하이라이트가 있다.

core와 모델, 의존성은 바뀌지 않았다.

## 계획과 달라진 점

1. **세로 범위를 선택 사각형이 아니라 글자 상자에서 가져온다.** 선택 사각형의 높이는 브라우저 대체 글꼴을 따라, 일본어 줄에서 글꼴 크기의 1.45배가 됐다(위아래로 크게 삐져나옴). pdf.js span 상자는 글꼴 크기 높이라 Acrobat의 하이라이트와 비슷하다.
2. **텍스트 끌기를 포인터 이벤트로 바꿨다.** 객체 레이어가 누름을 처리하면 마우스 호환 이벤트가 오지 않기 때문이다. 선택 도구의 끌기(M12)도 같은 코드를 쓰며, M12 테스트는 그대로 통과한다. 끄는 중 Esc로 취소하는 처리도 넣었다.
3. **pdf.js에 의존하지 않는 순수 함수를 `readingFrame.ts`로 옮겼다.** 단위 테스트를 쓰기 위해서다.

## 남은 위험

- **이미 하이라이트한 글자:** 선택 도구에서는 하이라이트가 위에 있어 그 글자를 더블클릭·끌어 선택할 수 없다(객체 우선, M12). 하이라이트 도구로 끄는 것은 된다.
- **하이라이트 너비:** PDF에 적힌 글자 폭을 따른다. 글자 모양보다 폭이 넓게 적힌 PDF는 줄 끝이 조금 더 길어 보일 수 있다. `text_select.pdf`의 한글 줄이 그렇다. 더블클릭으로 고른 단어는 뒤 공백까지 칠해진다(Windows 단어 선택).
- **기울어진 글자:** 쪽 회전이 아닌 텍스트 회전에는 축에 맞춘 사각형이 된다.
- **여러 단·표:** 선택 순서가 화면 순서와 다를 수 있고, 하이라이트도 그 선택을 따른다(M12와 같음).
- **쪽 맞춤 배율(기존 동작, 이번 범위 밖):** 세로·가로 쪽이 섞인 문서에서 "쪽 맞춤"을 누를 때의 현재 쪽 기준으로 배율이 정해져, 다른 방향의 쪽은 화면보다 클 수 있다. 샘플 테스트를 쓰다 알게 됐다.

## 사람 확인 점검표

2026-11-25 사용자가 아래 항목을 모두 확인했다(통과).

`target\release\HumblePDF.exe`(이 마일스톤으로 다시 빌드)와 `out\m13_sample.pdf`로 확인한다.

1. **샘플:** `out\m13_sample.pdf`를 Acrobat Reader와 Edge에서 연다. 네 쪽 모두 하이라이트가 글자 위치에 있고 글자가 가려지지 않는가.
2. **하이라이트 도구:** 앱에서 `tests\fixtures\text_select.pdf`와 평소 쓰는 PDF를 연다. 하이라이트 도구로 본문을 끌면 끄는 동안 선택이 보이고, 놓으면 그 글자에만 줄마다 붙는가.
   - 여러 줄을 끌거나 줄 끝 너머에서 놓아도 자연스러운가.
   - 빈 곳을 끌면 상자가 되는가.
3. **H 단축키:** 선택 도구로 텍스트를 고르고 H를 누르면 하이라이트되는가. Ctrl+Z로 한 번에 없어지는가.
4. **확대·회전:** 확대한 상태와 회전한 쪽에서도 맞는가.
5. **저장:** 저장한 파일을 Acrobat Reader·Edge에서 열면 같은 자리인가. HumblePDF로 다시 열면 하이라이트를 옮기거나 지울 수 있는가.
