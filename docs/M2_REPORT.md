# M2 페이지 정리와 병합 저장 보고서

2026-11-16 · 범위: SPEC 10장 M2

## 요약

| 수용 기준 | 결과 | 확인 방법 |
|---|---|---|
| 1. 순서 변경, 여러 장 선택, 삭제, 회전, Undo/Redo가 6.3절대로 동작한다 | 자동 테스트 통과. 끄는 감각은 사람 확인이 남음 | E2E `reorder, multi-select, …`, `dragging to the panel edge …`, 단위 테스트(model, history, selection, thumbDrag) |
| 2. 이미지 페이지의 맞춤 방식을 바꿀 수 있다 | 통과 | E2E(툴바와 오른쪽 클릭 메뉴), 단위 테스트(`setImageFit`), core 테스트(`image` 맞춤 저장) |
| 3. 다른 이름으로 저장한 PDF의 쪽수, 순서, 회전, 크기가 모델과 일치한다 | 통과 | core `organize.rs`(쪽 번호로 순서 확인), E2E 저장 후 CLI `inspect`로 비교 |
| 4. 저장 뒤에도 원본 파일은 그대로다 | 통과 | core(해시), E2E(SHA-256, 암호 PDF 포함) |
| 5. 소스와 같은 경로로 저장하려 하면 거부한다 | 통과 | core(모든 소스, 대소문자를 바꾼 경로), E2E(거부 알림 후 다시 묻기) |
| 6. 결과가 뷰어 세 종에서 열린다 | **사람 확인 필요** | `out/m2_sample.pdf`, 아래 점검표 |

마지막 실행에서 다음이 모두 통과했다.

- fmt, clippy
- `cargo test`: 34개(새 `organize.rs` 2개 포함)
- lint
- Vitest: 76개
- Playwright E2E: 21개(M2 5개 포함)

간헐 실패를 찾으려고 M2 E2E를 3번씩 반복했고, 15건이 모두 통과했다.

## 만든 것

- **모델과 이력** (`src/state/`)
  - 순수 함수 `movePages`, `deletePages`, `rotatePages`, `setImageFit`, `exportModel`
  - 스냅샷 이력 100칸(D25). 파일 추가도 한 칸이다. 바뀐 것이 없는 동작은 기록하지 않는다.
  - 선택: 클릭, Ctrl 토글, Shift 범위, Ctrl+A. 삭제나 Undo로 없어진 페이지는 선택에서 빠진다.
  - 파일은 선택한 페이지 중 가장 뒤에 있는 것 뒤에 들어간다. 선택이 없으면 끝에 들어간다(SPEC 6.1, M1에서 미룬 항목).
- **썸네일 패널**
  - 선택한 쪽은 굵은 파란 테두리, 현재 쪽은 옅은 테두리로 표시한다.
  - 끌어 옮기기(D24): 삽입선, "N쪽 옮기는 중" 표시, 가장자리 자동 스크롤, Esc 취소
  - 오른쪽 클릭 메뉴: 회전, 삭제, 이미지 맞춤. 선택되지 않은 쪽을 누르면 그 쪽만 선택한 뒤 연다.
- **툴바:** 새 문서, 파일 추가, 저장, 다른 이름으로 저장, 실행 취소/다시 실행, 회전, 삭제, 이미지 맞춤(대상에 이미지가 있을 때만)
- **단축키** (`src/app/shortcuts.ts`): 키는 `code`로 판정해 한글 입력 상태에서도 동작한다. 입력 칸이나 대화상자에서는 동작하지 않는다.

  | 키 | 동작 |
  |---|---|
  | Delete | 삭제 |
  | Ctrl+Z | 실행 취소 |
  | Ctrl+Y, Ctrl+Shift+Z | 다시 실행 |
  | Ctrl+A | 모두 선택 |
  | Ctrl+S | 저장 |
  | Ctrl+Shift+S | 다른 이름으로 저장 |
  | Ctrl+N | 새 문서 |
  | Ctrl+O | 파일 추가 |
  | Ctrl+[ , Ctrl+] | 회전 |

- **저장**
  - Tauri 명령 `export_document`: core의 `export_to_file`을 별도 스레드에서 부른다.
  - 진행 표시를 띄운다.
  - 결과 알림에 쪽수와 크기를 보여 준다. 암호 소스가 있으면 "출력에 암호가 걸리지 않는다"는 안내를 함께 띄운다.
  - 원본 경로를 고르면 거부 알림을 띄우고 대화상자를 다시 연다.
  - 페이지가 쓰지 않는 소스는 모델에서 빼고 보낸다.
- **저장하지 않은 변경 확인:** 새 문서(Ctrl+N)와 창 닫기에서 저장 / 저장 안 함 / 취소를 묻는다. 창 닫기에는 Tauri `onCloseRequested`와 `core:window:allow-destroy` 권한을 쓴다.
- **렌더링 캐시:** 본문 그림 캐시와 썸네일 캐시의 키에 회전과 맞춤을 넣었다. 돌린 페이지가 옛 그림을 늘려 보여 주지 않는다.
- **브라우저 모드 저장(D26):** 개발 서버 `/__export`가 CLI로 저장한다. E2E가 실제 core로 저장 흐름을 검증한다.
- **사람 확인 샘플:** `npm run sample`이 `out/m2_sample.pdf`(10쪽)를 만들고 확인 목록을 출력한다.

## 계획과 달라진 점, 발견한 문제

1. **오른쪽 클릭 메뉴를 비모달로 바꿨다.**
   - 문제: Radix의 모달 메뉴는 열릴 때 앱 전체에 `aria-hidden`을 건다. 그런데 누른 썸네일에 포커스가 남아 있어 브라우저가 접근성 경고를 냈다. E2E의 콘솔 검사에서 잡혔다.
   - 해결: `modal={false}`로 바꿨다.
2. **저장 기본 이름은 "첫 쪽의 소스"를 기준으로 한다.** SPEC의 "첫 소스"가 추가 순서인지 페이지 순서인지 모호했다. 내보내기의 기준 문서(D9)처럼 페이지 순서를 따르도록 SPEC 6.9를 고쳤다.
3. **파일 추가도 Undo 대상으로 했다.** 그래서 처음까지 Undo하면 빈 문서가 된다. SPEC 6.3에 적었다.
4. **저장 도우미 분리:** 저장 경로 계산은 백엔드(pdf.js)와 떼어 `savePath.ts`에 두었다. 단위 테스트에서 불러올 수 있게 하기 위해서다.
5. **테스트 훅 타입:** E2E의 `window.__viewer` 타입을 앱 정의(`ViewerHooks`)에서 가져오도록 바꿔 중복을 없앴다.
6. **exe가 3.6MB 커졌다.**
   - 원인: 저장 명령이 생기면서 core의 내보내기 코드가 exe에 링크되었다. 그 안에 번들 폰트(Pretendard 2.7MB, `include_bytes!`)가 들어 있다. M1까지는 exe가 파일 검사 코드만 써서 링커가 폰트를 뺐다.
   - 나머지 약 0.9MB는 내보내기·폰트 서브셋·이미지 인코딩 코드다.
   - 텍스트 저장(M5)에 꼭 필요한 폰트라 그대로 둔다.
   - 줄이려면 폰트를 압축해 넣는 방법이 있다. 필요하면 M7에서 제안한다.

## 남은 위험

- **키보드만으로는 페이지를 옮길 수 없다(D24).** 필요하면 "앞으로/뒤로 옮기기" 명령을 제안한다.
- **창 닫기 확인은 Tauri에서만 실제로 확인할 수 있다.** 브라우저 모드는 `beforeunload`만 쓴다. 사람 확인 항목이다.
- **저장 중 진행률이 없다.** 큰 문서에서는 "저장 중…"만 보인다. core가 진행률을 내지 않기 때문이다.

## 사람 확인 점검표

`npm.cmd run tauri dev`로 앱을 연다.

1. **썸네일 끌기:** `mixed_sizes.pdf`, `rotated.pdf`, `photo.jpg`를 추가한다.
   - 썸네일 하나를 끌어 다른 위치에 놓을 수 있는가
   - 삽입선이 놓일 자리를 정확히 보여 주는가
   - 끄는 감각이 자연스러운가
2. **여러 장 선택:** Ctrl+클릭과 Shift+클릭으로 여러 장을 골라 끈다. 한꺼번에 옮겨지는가.
3. **긴 문서에서 끌기:** `pages_300.pdf`에서 썸네일을 패널 아래 끝까지 끈다. 자동으로 스크롤되는가. Esc를 누르면 취소되는가.
4. **회전, 삭제, 맞춤:** 툴바, 오른쪽 클릭 메뉴, 단축키로 각각 해 본다.
   - Delete, Ctrl+[, Ctrl+]
   - 이미지 페이지에서 "A4에 맞춤"과 "이미지 크기"
5. **실행 취소:** Ctrl+Z와 Ctrl+Y로 처음까지 되돌렸다가 다시 실행할 수 있는가.
6. **저장**
   - Ctrl+S를 누르면 저장 대화상자가 `<첫 쪽 소스 이름>_편집.pdf`로 열리는가
   - 저장하면 알림이 뜨는가
   - 페이지를 하나 더 돌리고 Ctrl+S를 누르면 묻지 않고 같은 파일에 덮어쓰는가
7. **원본 거부:** 다른 이름으로 저장에서 열려 있는 원본 PDF를 고른다. Windows의 덮어쓰기 확인에서 "예"를 눌러도 거부 알림이 뜨고 대화상자가 다시 열리는가. 원본은 그대로인가.
8. **저장하지 않은 변경 확인**
   - 페이지를 바꾼 뒤 창의 X를 누르면 확인 창이 뜨는가
   - "취소"를 누르면 창이 남는가
   - "저장 안 함"을 누르면 창이 닫히는가
   - 저장한 직후에는 묻지 않고 닫히는가
9. **다른 뷰어에서 열기:** `npm.cmd run sample`이 만든 `out\m2_sample.pdf`와 6번에서 저장한 파일을 Acrobat Reader, Edge, Chrome에서 연다.
   - 비밀번호 없이 열리는가
   - 쪽 순서, 방향, 크기가 같은가(순서는 명령이 출력한 목록 참고)
   - 잘린 곳이 없는가
