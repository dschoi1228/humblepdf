## 만든 것

- 썸네일 오른쪽 클릭 메뉴의 "N쪽 내보내기…". N은 대상 쪽수다. 영어는 "Export N pages…", 일본어는 「Nページをエクスポート…」.
- `pagesDocument`(`src/state/model.ts`): 대상 쪽만 문서 순서대로 담은 모델. 쓰지 않는 소스는 기존 `exportModel`이 뺀다.
- `exportPages`(`src/app/save.ts`): 평탄화 내보내기와 같은 흐름(경로 묻기, 소스 거부, 진행 표시, 결과 알림)이다. 저장 상태는 바꾸지 않는다.
- 기본 이름의 접미사 `_발췌`, `_extract`, `_抜粋`. fixture 폴더에 실수로 저장한 파일이 커밋되지 않도록 `.gitignore`에도 넣었다.
- core와 Tauri 명령은 바꾸지 않았다.

## 사람 확인 점검표

2026-11-24 사용자가 1~3을 모두 확인했다(메뉴 문구 세 언어, 앱·Edge·Acrobat Reader에서 결과 파일, 저장 상태).

1. **메뉴:** 앱(`npm.cmd run tauri dev` 또는 새 exe)에서 PDF를 몇 개 열고 쪽 몇 개를 고른 뒤, 썸네일을 오른쪽 클릭한다.
   - "N쪽 내보내기…"의 N이 고른 쪽수와 같은가
   - 세 언어에서 문구가 자연스러운가
2. **결과:** 내보낸 파일을 앱과 Edge, Acrobat Reader에서 연다.
   - 고른 쪽만 문서 순서대로 들어 있는가
   - 회전과 주석이 그대로인가
   - 서명이 있다면 구워져 있는가
   - E2E가 만든 `out/m8/pages.pdf`(사각형이 있는 쪽 + 90° 돌린 쪽)를 열어 봐도 된다.
3. **저장 상태:** 내보낸 뒤 Ctrl+S를 누르면 다른 이름으로 저장을 묻는가(아직 저장한 적이 없다면). 창을 닫으면 저장할지 묻는가(편집했다면).
