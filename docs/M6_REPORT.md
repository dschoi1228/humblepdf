## 만든 것

- **core** (D36)
  - `restore.rs`: 전용 키의 JSON을 객체로 읽고, 다시 그린 상자가 `/Rect`와 0.01pt 안에서 같을 때만 되살린다.
  - 같은 판정을 세 곳에서 쓴다.
    - 열 때: `PageInfo.objects`
    - 렌더링용 바이트: `render_bytes`, 되살린 주석만 뺀 PDF
    - 저장할 때: 소스 페이지에서 빼고 현재 객체로 다시 쓴다.
  - CLI `render-bytes`. 바인딩을 다시 만들었다.
- **Tauri**
  - 렌더링용 바이트를 소스마다 한 번 만들어 메모리에 둔다. 암호도 메모리에만 둔다.
  - `export_document`에 `flatten`을 더했다.
- **프런트엔드**
  - 되살린 객체를 새 ID로 문서에 넣고, "편집 가능한 객체 N개를 되살렸습니다"를 알린다.
  - 툴바에 평탄화 내보내기 버튼(D37)을 더했다. 저장 상태는 바꾸지 않는다.
- **브라우저 모드:** 개발 서버 `/__inspect`, `/__render`가 CLI로 같은 결과를 준다. `/__export`는 `--flatten`을 넘긴다.
- **문자열:** ko, en, ja
- **샘플:** `npm run sample`이 두 파일을 더 만든다.
  - `out/m6_reopened.pdf`: m3·m5 샘플을 다시 열어 저장. 객체 37개가 되살아났다(24 + 13, 모두).
  - `out/m6_flattened.pdf`: 같은 모델을 평탄화

## 계획과 달라진 점, 발견한 문제

1. **E2E 화면 비교에서 알림이 페이지를 가렸다.** 다시 연 뒤의 "되살렸습니다" 알림이 페이지 오른쪽 아래를 덮어, 처음 비교에서 0.28%가 달랐다. 두 번 그려졌다면 하이라이트 영역만으로 1% 이상 차이가 난다. 스크린숏을 찍는 동안 알림을 숨기도록 고쳤다. 지금은 0.2% 기준 안이다.
2. **위치는 그대로 두고 내용만 바꾼 주석은 앱의 JSON으로 되살린다.** 되살리기 판정은 `/Rect`와 JSON만 본다. 다른 프로그램이 내용(`/Contents`)이나 모양(`/AP`)만 바꾸고 위치는 그대로 두면 앱의 JSON으로 되살린다. 그래서 그 변경은 다시 저장할 때 사라진다. SPEC이 정한 판정(`/Rect` 비교)대로이며, 남은 위험에 적는다.

## 남은 위험

- **위치를 바꾸지 않은 다른 프로그램의 수정:** 내용이나 색만 바꾼 경우 앱의 JSON이 이긴다(위 2번). 필요하면 M7 이후에 `/AP` 해시 비교를 제안한다.
- **이후 버전의 모양 계산 변경:** 폰트나 모양 계산이 바뀌면 예전 파일의 주석이 되살아나지 않고 원본 주석으로 남을 수 있다. 데이터 손실은 없다.
- **큰 파일:** 되살린 주석이 있는 파일만 렌더링용 바이트를 한 벌 더 메모리에 둔다. 50MB 파일이라면 50MB를 더 쓴다. 앱이 저장한 큰 파일을 다시 여는 경우에만 해당한다.

## 사람 확인 점검표

`npm.cmd run tauri dev`로 앱을 연다.

1. **다시 열기:** 도형, 하이라이트, 텍스트를 그려 저장한다. 새 문서(Ctrl+N)에서 그 파일을 다시 추가한다.
   - "되살렸습니다" 알림이 뜨는가
   - 객체를 선택, 이동, 수정할 수 있는가
   - 겹쳐 그려진 곳이 없는가
2. **다시 저장:** 하나를 지우고 하나를 옮겨 다른 이름으로 저장한다. Acrobat Reader나 Edge에서 지운 것은 없고 옮긴 것은 새 위치에 있는가.
3. **다른 프로그램이 옮긴 주석:** 앱에서 저장한 파일을 Acrobat Reader(또는 Edge)에서 열어 주석 하나를 옮기고 저장한다. 그 파일을 앱에 추가한다.
   - 옮긴 주석은 객체로 선택되지 않고 그림으로 보이는가
   - 나머지는 객체로 돌아오는가
   - 다시 저장해도 옮긴 주석이 그대로 남는가
4. **평탄화:** 툴바의 평탄화 내보내기 버튼으로 내보낸다.
   - 알림이 뜨는가
   - 그 뒤 Ctrl+S는 원래 저장 파일에 저장되는가(평탄화 파일이 아님)
5. **다른 뷰어:** `npm.cmd run sample`이 만든 `out\m6_reopened.pdf`, `out\m6_flattened.pdf`와 앱에서 내보낸 평탄화 파일을 Acrobat Reader, Edge, Chrome에서 연다.
   - 두 파일 모두 m3·m5 샘플과 같은 모습인가
   - 평탄화 파일에서는 주석이 선택되지 않는가
