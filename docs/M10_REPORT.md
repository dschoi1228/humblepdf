# M10 인쇄 보고서

2026-11-25 · 범위: SPEC 6.11, 10장 M10 · 결정: DECISIONS D45

인쇄는 SPEC의 비목표였다. 사용자 요청으로 0.2에 넣었다. 설치 프로그램은 M11로 옮겼다.

## 요약

| 수용 기준 | 결과 | 확인 방법 |
|---|---|---|
| 문서 전체(Ctrl+P, 툴바)와 고른 쪽(썸네일 메뉴)을 인쇄한다. 내용은 평탄화 내보내기와 같고 고른 쪽은 문서 순서다 | 통과 | E2E `print.spec.ts`: Ctrl+P와 툴바 버튼, 인쇄용 PDF를 core로 다시 읽어 쪽수·상자·되살릴 객체 없음(평탄화) 확인. "2쪽 인쇄…"가 1쪽, 3쪽 순서로 나간다 |
| PDF 뷰어로 벡터 인쇄하고, 뷰어가 없으면 쪽 크기별 이미지로 인쇄한다 | 자동 테스트 통과, 실제 인쇄는 사람 확인 | E2E: PDF 뷰어 경로(blob 프레임), 이미지 경로(쪽마다 `@page` 크기, 200dpi). 실제 앱: 개발 빌드와 release 빌드에서 숨긴 프레임으로 Edge 인쇄 대화상자가 뜨고 쪽 크기가 섞인 문서와 회전한 쪽이 미리보기에 그대로 나왔다(앱 창만 캡처해 확인) |
| 저장으로 치지 않고 소스를 바꾸지 않는다 | 통과 | E2E: 인쇄 뒤 Ctrl+S 대상 없음, "저장하지 않은 변경" 그대로, 소스 SHA-256 그대로 |

마지막 실행에서 다음이 모두 통과했다.

- fmt, clippy
- `cargo test` 63개
- lint
- Vitest 176개(단축키 도움말 표가 Ctrl+P를 포함해 실제 키 매핑과 같은지 기존 테스트가 확인)
- Playwright E2E 50개(새 테스트 2개)

## 만든 것

- **Tauri** `print_document`: 평탄화 PDF를 메모리에서 만들어 원시 바이트로 돌려준다.
- **프런트엔드** `src/app/print.ts`
  - PDF 뷰어 경로: 화면 밖에 숨긴 iframe에 blob PDF를 넣고 인쇄 대화상자를 연다.
  - 이미지 경로: PDF.js로 200dpi PNG를 그려 쪽 크기마다 이름 붙인 `@page`로 인쇄한다.
  - 준비하는 동안 "인쇄할 PDF를 만들고 있습니다…"를 보인다.
- 툴바 인쇄 버튼, Ctrl+P(입력 칸에서도 앱 화면 인쇄를 막는다), 썸네일 메뉴 "N쪽 인쇄…", 단축키 도움말, 세 언어 문구.
- CSP에 `frame-src 'self' blob:`.
- 브라우저 모드: 개발 서버가 `out/e2e/print/`에 평탄화 PDF를 만들고 페이지가 읽어 간다.

## 계획과 달라진 점

- 시험을 먼저 했다. 앱 안의 Edge PDF 뷰어가 blob PDF를 열고 인쇄 대화상자를 띄우는 것을 확인한 뒤 구현했다.
- 이미지 경로는 자동 테스트로만 확인했다. 이 PC의 앱에서는 PDF 뷰어가 있어 쓰이지 않는다.

## 남은 위험

- 대화상자는 Edge의 것이라 앱 언어가 아니라 Windows 언어를 따른다.
- 프린터 드라이버마다 여백과 배율 기본값이 다르다. 대화상자의 "기타 설정"에서 배율(실제 크기/맞춤)을 고를 수 있다.
- 쪽이 아주 많은 문서는 PDF를 만드는 동안 잠시 기다린다(저장과 같은 시간).

## 사람 확인 점검표

2026-11-25 사용자가 1~3을 모두 확인했다.

확인 중 다른 문제를 하나 발견해 고쳤다. 빈 앱에 여러 PDF를 끌어다 놓아 합친 뒤 닫으면 저장할지 묻지 않았다. D42의 "빈 문서에 연 파일은 변경이 아니다" 규칙이 파일 수를 보지 않았기 때문이다. 이제 한 번에 하나를 열었을 때만 변경이 아니다(D42에 기록, 단위 테스트와 E2E 추가).

새 exe(`target\release\HumblePDF.exe`)로 확인한다.

1. **문서 전체:** PDF와 이미지를 몇 개 열고 텍스트·도형·서명을 놓은 뒤 Ctrl+P(또는 툴바의 프린터 버튼)를 누른다.
   - Edge 인쇄 대화상자가 뜨고 미리보기가 화면과 같은가(쪽 크기가 다른 쪽, 회전한 쪽 포함)
   - "Microsoft Print to PDF"로 인쇄한 파일과 실제 프린터 출력이 화면과 같은가. 글자를 확대해도 선명한가
2. **고른 쪽:** 썸네일에서 쪽 몇 개를 고르고 오른쪽 클릭 → "N쪽 인쇄…". 그 쪽만 문서 순서대로 나오는가
3. **상태:** 인쇄한 뒤 창을 닫을 때 편집했다면 저장할지 묻는가(인쇄는 저장이 아니다). 입력 칸에서 Ctrl+P를 눌러도 앱 화면이 아니라 문서가 인쇄되는가
