- Vitest 205개(새 테스트 7개)

## 만든 것

- `newSignature`가 기억한 폭(`width`)을 받는다. 없으면 화면 쪽 폭의 20%다(25%에서 줄임). 쪽에 맞게 줄이는 계산은 그대로다.
- `signatureWidth(obj)`: 서명이 똑바로 선 방향의 폭이다. 회전 90·270이면 사용자 공간의 세로다.
- 핸들로 크기 조절을 마치면 `signatureStore.rememberWidth`가 기억한다. 클릭 배치와 배치 미리보기가 같은 값을 쓴다.
- 설정 저장소(D38)에 `signatureWidths`를 더했다. 보관함 ID와 숫자만 들어간다. 서명을 지우면 그 항목을 지우고, 시작할 때 보관함에 없는 ID를 버린다.
- core, 출력 PDF, 문서 모델, Tauri 백엔드는 바뀌지 않았다.

함께 고친 문서: SPEC 2장 비목표의 "본문 검색"(M14에서 만들었으므로 뺐다), README.

## 남은 위험

- 기억은 PC의 WebView 설정에 있다. 서명 보관함 폴더만 다른 PC로 옮기면 크기는 따라가지 않는다(처음 크기 20%로 놓인다).
- 같은 서명을 문서마다 다른 크기로 쓰면, 마지막에 조절한 크기가 다음 기본이 된다.

## 사람 확인 점검표

2026-11-26 사용자가 아래 항목을 모두 확인했다(통과).

`target\release\HumblePDF.exe`(이 마일스톤으로 다시 빌드)로 확인한다.

1. **처음 크기:** 크기를 바꾼 적 없는 서명을 A4 쪽에 놓으면 예전보다 작게(쪽 폭의 20%) 놓이는가.
2. **기억:** 놓은 서명을 모서리 핸들로 원하는 크기로 줄인다. 다시 서명 도구로 놓으면, 포인터를 따라다니는 미리보기와 놓인 서명이 줄인 크기인가.
3. **다른 쪽·배율:** 다른 크기나 가로 방향의 쪽, 확대·축소한 상태에서도 같은 실제 크기로 놓이는가.
4. **재시작:** 앱을 껐다 켜고 같은 서명을 놓으면 줄인 크기 그대로인가.
