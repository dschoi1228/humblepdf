## 계획과 달라진 점, 발견한 문제

1. **exe 감소폭이 예상보다 작다(−4.7MB 예상, −2.0MB 실측).** Tauri는 프런트엔드 자산을 압축해 exe에 넣는다. 그래서 중복되어 있던 폰트도 압축된 크기만큼만 차지하고 있었다. 설정 유지 플러그인이 더한 크기도 조금 있다.
2. **MPL-2.0 크레이트 5개를 발견했다.** Tauri를 통해 M0부터 들어와 있었다(cssparser, cssparser-macros, selectors, dtoa-short, option-ext). CLAUDE.md 규칙 9의 허용 목록에 없어서 여쭈었다. 이 5개만 고치지 않고 쓰는 조건으로 예외 허용하기로 했다(D40, 규칙 9에 기록). 다른 MPL이 들어오면 `npm run notices`가 실패한다.
3. **고지 목록에서 선택 설치 패키지를 뺐다.** 처음 목록에는 `@napi-rs/canvas`처럼 번들에 들어가지 않는 플랫폼용 선택 패키지가 들어 있었다. pdf.js가 Node에서만 쓴다.
4. **저작권 표기는 "HumblePDF contributors"다.** CLAUDE.md 규칙 8(사용자 이름을 저장소에 넣지 않는다)에 따랐다. 다른 표기를 원하면 바꾼다.

## 남은 위험

- **CI의 E2E:** 러너의 글꼴 렌더링이나 화면 배율 때문에 화면 일치(1px) 테스트가 로컬과 다르게 나올 수 있다. 첫 실행 결과를 본 뒤 대응한다.
- **코드 서명 없음:** SmartScreen 경고가 뜬다. README와 릴리스 설명에 안내했다. 코드 서명은 SPEC 후순위다.
- **일본어 번역:** 원어민 검토 전이다(README에 기여 안내).

## 사람 확인 점검표

1. **창 크기:** `npm.cmd run tauri dev`(또는 빌드한 exe)를 연다.
   - 창 크기와 위치를 바꾸고 닫았다가 다시 열면 그대로인가
   - 최대화한 채 닫으면 최대화로 열리는가
2. **최근 설정:** 사각형 색·두께, 텍스트 크기, 썸네일 패널 닫기, 쪽 맞춤을 바꾼 뒤 다시 열면 그대로인가.
3. **도움말과 정보:** F1과 툴바의 `?`, `i` 버튼. 세 언어에서 문구가 자연스러운가.
4. **전체 점검:** `docs/RELEASE_CHECKLIST.md`의 1~6절
5. **공개 전:** 점검표 7절(KIPRIS 상표 검색 등)
6. **CI:** GitHub 저장소의 Actions 탭에서 CI가 통과했는가
